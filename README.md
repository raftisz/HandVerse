# HandVerse ✋🌌

**Control particles, write in the air, and open filter portals — with your bare hands and a webcam.**

ควบคุมอนุภาค เขียนกลางอากาศ และเปิดพอร์ทัลฟิลเตอร์ ด้วยมือเปล่าผ่านกล้องเว็บแคม
ใช้ MediaPipe จับจุดข้อนิ้ว 21 จุด แล้วแปลงเป็นท่าทาง (ด้วยกฎ หรือโมเดลที่เทรนจากข้อมูล HaGRID)

> 🎥 GIF เดโมกำลังตามมา

## จุดเด่นทางเทคนิค

- **แยกมือซ้าย/ขวาแบบไม่สลับไปมา** — จำมือจากตำแหน่ง + โหวตป้ายซ้าย/ขวาหลายเฟรม (ป้ายจาก MediaPipe กระโดดได้)
- **กรองมือสั่นด้วย One Euro Filter** — ขยับช้า = นิ่ง, ขยับเร็ว = ตามทัน
- **ตรวจนิ้วเหยียด/งอแบบ 3 มิติ + hysteresis** — ชี้นิ้วไปทางไหนก็จับได้ ไม่สลับไปมาตอนนิ้วงอครึ่งๆ
- **โมเดลจำท่ามือ (MLP)** เทรนจากจุดข้อนิ้วของ [HaGRID](https://github.com/ai-forever/hagrid) ~42,000 มือ — ความแม่นยำ 97.9% กับมือที่ไม่ได้ใช้เทรน รันในเกมด้วย numpy อย่างเดียว (กด `M` สลับกับกฎเดิมได้)
- **ฟิลเตอร์ภาพด้วย OpenCV** — sketch, glitch, neon, pixel, thermal, ขาวดำแบบฟิล์ม

## วิธีรัน


## วิธีเล่น

**มือซ้าย = คุมอนุภาค**

| ท่า | ผล |
|---|---|
| ✋ แบมือ | อนุภาคแตกกระจาย (สีรุ้ง) |
| ✊ กำมือ | รวมเป็นลูกพลังงาน |
| ☝️ ชูนิ้วชี้ | ดาวเคราะห์มีวงแหวน |
| ✌️ ชูสองนิ้ว | หัวใจ |
| 🖕 ชูนิ้วกลาง | ตัวหนังสืออนุภาค |
| 🤙 ชูนิ้วก้อย | ผลัก/ดูดอนุภาค (Space สลับ) |
| ขยับ / ใกล้กล้อง / เอียงมือ | รูปลอยตาม / ซูม / เอียง |

**มือขวา = เขียนกลางอากาศ**

| ท่า | ผล |
|---|---|
| ☝️ ชูนิ้วชี้ | เขียน |
| ✋ แบมือ | ยกปากกา |
| 3 นิ้ว (ก้อยพับ) | ยางลบ |
| 👌 โป้งแตะชี้ | เปลี่ยนสีปากกา |
| ✊ กำค้าง 3 วิ | ตัวหนังสือกลายเป็นอนุภาค |

**โหมดพอร์ทัล (กด P)**
- สองมือทำตัว L เป็นกรอบ → ภาพในกรอบติดฟิลเตอร์ (SKETCH, GLITCH, NEON, PIXEL, THERMAL, DARKMODE)
- กลับหัวตัว L ข้างหนึ่ง → กรอบตัว X (นาฬิกาทราย)
- ก้อยแตะโป้ง → ฟิลเตอร์ถัดไป
- กางกรอบใหญ่แล้วถือนิ่ง 2.5 วิ → แคปรูป

**ปุ่ม**: `R` อัดวิดีโอ · `S` แคปหน้าจอ · `C` ลบกระดาน · `H` สลับหน้าที่มือ · `M` สลับ โมเดล/กฎ · `P` พอร์ทัล · `ESC` ออก

## โครงสร้างโปรเจกต์

```
HandVerse/
├── main.py            ไฟล์หลัก: วาดจอ + ปุ่มคีย์บอร์ด
├── fx/
│   ├── config.py      ค่าตั้งค่าทั้งหมด (อยากปรับอะไร แก้ที่นี่)
│   ├── shapes.py      รูปทรงอนุภาค
│   ├── hands.py       จับมือ, ตัดสินท่า, ตัวกรองมือสั่น, แตะนิ้ว
│   ├── portal.py      ฟิลเตอร์ + กรอบพอร์ทัล + แคปรูป
│   ├── camera.py      thread กล้อง
│   └── recorder.py    อัดวิดีโอ / แคปหน้าจอ
├── ml/
│   ├── gesture_model.py   โมเดลจำท่ามือ (รันด้วย numpy อย่างเดียว)
│   ├── train.py           เทรน + เทียบกับกฎเดิม
│   ├── collect.py         อัดท่ามือของตัวเอง
│   └── data/              ข้อมูล HaGRID + ท่ามือที่อัด (ไม่ได้อัปขึ้น GitHub)
└── recordings/        วิดีโอและรูปที่แคป (ไม่ได้อัปขึ้น GitHub)
```

## เทรนโมเดลจำท่ามือ (ไม่บังคับ)

```bash
python ml/collect.py train      # อัดท่ามือ ท่าละ ~200
python ml/collect.py test       # อัดชุดทดสอบ ท่าละ ~100 (คนละรอบ)
pip install scikit-learn
# โหลดจุดข้อนิ้ว HaGRID (annotations_with_landmarks) จาก github.com/ai-forever/hagrid แล้วแตกไฟล์
python ml/train.py path/to/annotations   # เทียบ กฎเดิม / HaGRID / มือตัวเอง / ผสม
```

ข้อมูลจาก [HaGRID](https://github.com/ai-forever/hagrid) (ใช้เฉพาะจุดข้อนิ้ว ไม่ต้องโหลดภาพ)
